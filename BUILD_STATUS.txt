CrashLogger v0.2 source package status

This package contains the v0.2 source changes and intentionally does NOT include
the uploaded archive's old build/CrashLogger.asi binary.

Validation performed in this environment:

- CMake source-list coverage check

MSVC-Wine toolchain points at /mnt/sata/msvc/bin/x64 and that toolchain/Windows SDK
is not installed here. Build on the project's configured MSVC-Wine environment
before deploying the v0.2 ASI into the game.
